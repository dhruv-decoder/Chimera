# Demo script (about 3 minutes)

A tight path that lands every judging criterion. Run `make dev`, open
`http://localhost:3000`, and follow this.

## 0. One-line framing (say this first)
"Chimera is a closed loop: an AI red team evolves fraud against a live detector,
and the detector hardens on exactly what breaks through. One system, three
pillars, one loop."

## 1. Landing story (25s) - the thesis, scrolled
- Start on the landing page. "Fraud that learns needs a defense that learns back."
- Scroll through the hardening curve as it reveals round by round: "Baseline
  catches 73%. The red team evolves evasion and collapses it to 19%. I retrain
  and recover to 83%, then it converges. That collapse-and-recover is the whole
  thesis."
- Scroll to the agentic section: "And the vector most teams will miss: a hijacked
  AI shopping agent looks identical to a legitimate one - I catch it on credential
  integrity." Click **Open the live console**.

## 2. Threat Matrix (25s) - Identify / diversity
- "GenAI payment fraud mapped as an ATT&CK-style matrix across the kill chain -
  16 techniques, 9 simulated end to end, each with the observable signatures my
  detector uses and cited 2026 sources."
- Click **Delegated-token / agent-identity abuse** and **Deepfake-authorised push**.

## 3. Attack Lab (45s) - Generate + Defend + Explainability, live
- Pick **AGENT-HIJACK**, click **Launch campaign**.
- "The detector scores every event live. Open a flagged row - per-event reason
  codes from exact SHAP. Notice the agent-identity features doing the work:
  attestation, directory trust, mandate-cap breach."
- Point at the **red-team ideation** card: "That's a live open-weight model
  (gpt-oss-120b on Groq) proposing the next variant, grounded in my RAG corpus."
- Drag the **attestation** / **cap_breach** knobs toward mimicry and relaunch:
  "Watch recall fall as the hijack blends into legitimate agent traffic - that's
  the red team at work."

## 4. Closed Loop (45s) - the winning view
- Point at the **multi-agent pipeline** at the top: "Four agents run as a LangGraph
  state machine - recon, red team, attack, blue team - and the graph cycles. The
  trace below is the real execution; this report was generated by that graph."
- "This is the whole thesis in one chart."
- Round 1: "The red team's evasion drops aggregate recall from 73% to 19% - nearly
  everything gets through a static model. I retrain on those samples and recover
  to 83%."
- "By round 3 the red team can't find easy evasion anymore. The loop converges."
- Point at Round 1 ideation, tagged `groq:openai/gpt-oss-120b`: "Real model
  outputs, in the real loop - not canned."
- Per-vector: "Behavioural attacks can be tuned to near-invisibility; structural
  ones can't. The loop recovers the evadable classes."

## 5. Network Graph (20s) - fidelity of coordinated fraud
- "Real-time transfer graph. Red nodes touch fraud. Mule rings show up as fan-in /
  fan-out structure - that's why I built graph features, not just per-transaction."

## 6. Detection (25s) - efficacy + honesty
- "Strong in-distribution numbers, reported honestly. The cost-aware operating
  point recovers 100% of fraud value at ~140 alerts per 10k - what a bank signs off."
- "And the novelty table: remove delegated-token abuse entirely from training and
  the supervised model catches 15% - the agent-identity features and novelty channel
  recover 100%. That's my answer to 'novel, emerging'."

## Close (10s)
- "Synthetic data, defensive tooling, free-tier stack, reproducible from a seed.
  The paid-infra upgrades - managed embeddings, a temporal GNN, a hosted endpoint -
  are quality dials, not a rewrite. That's Chimera."

## If asked hard questions
- **AUC looks perfect?** "On naive campaigns, yes - strong signatures. I inject
  hard negatives so no single feature separates the classes (best single-feature
  AUC ~0.84), and report PR-AUC, FPR-at-recall and value recovered. The real test
  is adversarial: recall drops to 19% before the loop recovers it."
- **Is the agent-hijack vector actually hard?** "In-distribution I catch it
  because I built the feature family for it. The honest test is leave-one-out:
  unseen, the supervised model gets 15%; novelty recovers 100%. And it shares
  infrastructure and cadence with legitimate agents by construction - only
  credential integrity separates them."
- **Where's the GenAI?** "A LangGraph multi-agent loop, a live gpt-oss RAG ideation
  agent, a black-box evolutionary red team, and agentic-commerce identity abuse
  simulated end to end."
- **Real payments?** "Schema is what a switch sees at auth. Features move to a
  streaming store; the loop becomes a scheduled retrain on a labelled buffer."
